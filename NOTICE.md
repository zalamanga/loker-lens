# Asal kode dan isi repository

Loker Lens berasal dari aplikasi Node/HTML/CSS/JavaScript lokal milik pemilik akun repository. Logika ekstraksi teks, profil kata kunci, filter dan identitas briefcase hijau/limau dipertahankan serta dirapikan. Modul cache, adapter berbatas, model, pengendali request dan pengujian ditata ulang untuk alur yang terdokumentasi.

Repository ini tidak menyertakan distribusi paket pihak ketiga. Node.js dan browser menyediakan runtime aplikasi utama. Konektor JobStreet opsional mengunduh checkout MIT omkarcloud/jobstreet-scraper dan dependensi Python terkunci ke direktori lokal yang diabaikan Git. Revisi dan atribusinya ada pada [catatan layanan](docs/JOBSTREET-SERVICE.md). Tidak ada klaim lisensi atas data penyedia eksternal; pemakaian layanan sumber mengikuti ketentuan pemilik layanan tersebut.

Seluruh post mode demo merupakan contoh sintetis. Nama organisasi, judul, persyaratan dan lampiran contoh bukan penawaran kerja nyata. Halaman sumber demo hanya menampilkan teks lokal. Berkas cache lama, profil browser, screenshot lama, rekaman penggunaan dan aplikasi permainan terpisah tidak dipublikasikan.

Adapter live hanya membaca endpoint publik yang tetap. Aplikasi tidak menjamin post masih terbuka, isi lampiran sudah ditinjau, kecocokan pelamar, atau hasil perekrutan.
